Use case 01 / 04

Monitoring Pariwisata Daerah

Dashboard dinas + input pengelola · offline-first

Stack gratis

FrontendNext.js PWA → VercelFREE
DB · AuthSupabase (Postgres + RLS)FREE
OfflineService Worker + Dexie
Peta · ChartLeaflet + OSM · Recharts
{{ICO_BULB}} Kenapa

Bobot penilaian terbesar ada di akurasi data (30%), bukan tampilan. Postgres + RLS bikin tiap pengelola hanya melihat destinasinya sendiri, dinas melihat semuanya.

{{ICO_ALERT}} Gotcha

Sinyal lemah di pesisir dan perbukitan, jadi offline itu wajib dan bukan tambahan. Hitung pendapatan dari rentang nomor seri karcis, bukan total yang diketik. Seed 12–24 bulan supaya musiman terlihat.

Deploy git push Vercel build Supabase + RLS Live URL
Use case 02 / 04

Solo Technopark

Peta game interaktif · QR checkpoint · dua bahasa

Stack gratis

FrontendNext.js / Vite → VercelFREE
PetaSVG 2D ilustratif, bukan 3D
Konten · CMSSupabase / JSON + admin pageFREE
i18nnext-intl, teks eksternal
{{ICO_BULB}} Kenapa

Peta dimodelkan sebagai data — zona, titik, aturan akses, konten ID dan EN — supaya staf non-teknis bisa mengubah isi tanpa deploy. Bobotnya 15%, setara showcase mode.

{{ICO_ALERT}} Gotcha

Jangan pakai GPS di lahan 7,2 ha, pakai QR checkpoint. Enam puluh siswa serentak di wifi kawasan: muat sekali, lalu jalan dari cache. Showcase mode cukup route terpisah /showcase untuk layar besar.

Deploy git push Vercel build Supabase (konten) Live URL + QR
Use case 03 / 04

Desa Digital

ERP pemerintahan desa · data induk + satu pilar

Stack gratis

FrontendNext.js PWA → VercelFREE
DB · AuthSupabase + Row Level SecurityFREE
Surat / PDFpdfmake · react-pdf
Data sintetisFaker.js (locale id_ID)FREE
{{ICO_BULB}} Kenapa

Satu data induk penduduk dan keluarga yang dibaca semua modul. Hak akses ditegakkan di RLS, bukan sekadar disembunyikan di tampilan — privasi berbobot 15%.

{{ICO_ALERT}} Gotcha

Data penduduk wajib sintetis: NIK, KK, dan nama palsu. Masukkan kekacauannya dengan sengaja — duplikat, salah ejaan, warga pindah. Riwayat perubahan = tabel audit append-only. Siskeudes jangan dibangun ulang.

Deploy git push Vercel build Supabase + RLS + audit log Live URL
Use case 04 / 04

HISWA-RECRON

Game penemuan karier · stan dan sekolah, satu codebase

Stack gratis

SiteVite / Astro → Netlify · CF PagesFREE
OfflineService Worker (Workbox)FREE
Teks NLJSON i18n, tanpa hardcode
CounterSupabase, agregat sajaFREE
{{ICO_BULB}} Kenapa

Tanpa akun dan tanpa backend berat, jadi static build + CDN: biaya nol dan tetap hidup saat wifi acara 30.000 orang tumbang.

{{ICO_ALERT}} Gotcha

Perangkat bersama, jadi reset harus instan dan progres tidak boleh nyangkut di localStorage. Satu URL untuk dua konteks lewat query param (?ctx=stand / ?ctx=school), bukan dua repo. Tanpa analitik pihak ketiga — pemain di bawah umur, tunduk AVG.

Deploy git push Build static CDN Netlify / CF Live URL + QR
